💾 Save / Load / Export

Character Animator — Project Management

1Export for Unity

Saves a single Project JSON containing voxels + groups + pivots + animation params.

After download, place the file in the appropriate folder:

voxel_characters/ — animated characters (hoodlums, civilians, etc.)
voxel_buildings/ — static buildings and structures
voxel_accessories/ — hats, weapons, held items
voxel_decor/ — props, furniture, environmental items

Then in Unity: Tools > Voxel Import > [matching category]

2Load Existing Project

Import a previously saved Project JSON to continue editing.

🔧 Advanced — Individual Exports

Export individual data files. Only needed for debugging or manual pipeline use.
