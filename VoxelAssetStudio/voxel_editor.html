👕 Clothing & Accessories

Loads character_base_naked.json as the starting point for clothing variation.

Paint each voxel with a clothing region tag. Press C to switch to region paint tool. These tags tell the procedural clothing system which material to apply where.

No presets saved yet

Save current clothing state as a preset, or apply a saved preset onto the base template.

Removes all clothing/accessory voxels and material swaps, restoring the naked base.

How it works:
1. Load the naked base template
2. Paint clothing regions (skin, face, hair, torso, arms, legs, feet)
3. Auto-assign as starting point, then fine-tune with C tool
4. Export .regions.json — saved with the base template
5. Procedural clothing system reads regions to apply materials

Regions are body-agnostic tags. Same region map works for any character sharing the same anatomy.

📦 Volume Controls

📐 Set Size Directly

Type exact W/H/D. Model auto-centers in the new volume. Voxels outside new bounds are deleted if shrinking.

📐+ Expand Per-Side

Add space on specific sides. −Side shifts voxels inward (expands that direction). +Side adds empty space on the far side. Equal expansion mirrors the value to both sides — ideal for mirror mode.

🤖 Auto-Size to Range of Motion

Computes the farthest voxel from the model center, then sizes a cube to 2 × maxReach + 2 × padding. Guarantees any pose fits without clipping (Steel Tide approach).
