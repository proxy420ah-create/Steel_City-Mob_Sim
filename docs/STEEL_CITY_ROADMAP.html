Rendering Tiers
DONE
Three-tier strategy: Bake / Instance / Individual
  • Tier 1: Sector baking (static buildings → 1 mesh per sector)
  • Tier 2: GPU instancing (batched dynamic — NPCs, vehicles, door leaves)
  • Tier 3: Individual draw (unique mutation — destruction)
  • Decision checklist documented
