Phase 1: Static Sector TRS Cache
COMPLETE
Cache Matrix4x4[] for sector buildings — stop rebuilding 984 matrices per frame
  • BakedSector gets cachedMatrices field
  • Build matrices once at RegisterSector time via BuildSectorMatrices()
  • 984 TRS calls/frame → 0, 10 array allocs/frame → 0
  • Bonus: vSync + 120fps cap, HUD frame time metrics (ms + min/max/avg + GPU/CPU)
  • Commit b184e99 — Aug 9, 2026
○
Phase 2: Buffer Pooling + SubUpdates
PLANNED
ComputeBufferMode.SubUpdates + BeginWrite/EndWrite for zero-GC buffer updates
  • Replace SetData with BeginWrite/EndWrite for instance offsets
  • Pool reusable ComputeBuffers across frames
  • Zero GC allocs per frame — low risk
○
Phase 3: DrawMeshInstancedIndirect
PLANNED
Replace DrawMeshInstanced with indirect draw — instance count from GPU buffer
  • Create IndirectArguments GraphicsBuffer per sector
  • CPU writes instance count initially (no GPU culling yet)
  • Removes 1023 instance cap — medium risk
○
Phase 4: Compute Shader Frustum Culling
PLANNED
GPU compute shader culls invisible instances — no CPU readback
  • New SectorCull.compute shader
  • InterlockedAdd for compacted visible index list
  • Shader reads _VisibleIndices[unity_InstanceID] — medium risk
○
Phase 5: GPU-Side LOD
PLANNED
Compute shader assigns LOD tier per instance — distant buildings get fewer raymarch steps
  • LOD tiers: full / half / quarter / cull based on screen-space size
  • Hysteresis to prevent flickering at LOD boundaries
  • Shader scales maxSteps per instance — higher risk
○
Phase 6: Remove 1023 Cap + Scale Test
PLANNED
Merge sectors, test with 500-1000 block cities
  • Optionally merge all building sectors into 1 mega-sector
  • Test with 500-block city layout
  • Target: ~3 draw calls for entire city — low risk if 3-4 solid

Invariant Computation Audit — 6 Pending Candidates
IN PROGRESS
"Do Once, Not Repeat Constantly" — identified during Phase 1 audit. See INVARIANT_COMPUTATION_PRINCIPLE.md
  • 🔴 #1 Sector Bounds: cache Bounds at RegisterSector (10 allocs/frame → 0)
  • 🔴 #2 PropBlock Clear: skip Clear()+re-set when buffers unchanged (10+ API calls/frame saved)
  • 🟡 #3 Group Size/Pad: cache paddedSize+paddedHalf at group creation
  • 🟡 #4 Chunk Tight AABB: cache tightSize+boundsRadius at load (computed 2× per chunk now)
  • 🟡 #5 Corners Array: reuse static Vector3[8] scratch (N allocs/frame → 0)
  • 🟢 #6 Instanced Arrays: pool offset/matrix arrays per group (GC scales with char count)
  • ✅ Case Study 1: TRS Matrix Cache (Phase 1 — 984 builds/frame → 0)
  • ✅ Case Study 2: Collision World Flat Array (78s → 371ms, 211× faster)
