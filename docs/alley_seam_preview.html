How Alley Seams Work

  • Block structure: Each BLOCK = 3x3 building plots (8 buildings + center courtyard). Surrounded by a sidewalk ring. groundTileSize = (BuildingVoxelWidth * buildingsPerBlockRow * voxelSize) + sidewalkWidth * 2
  • Current system: Every seam between blocks is a roadWidth road. Uniform spacing: spacing = groundTileSize + roadWidth
  • Proposed system: Each seam is typed as Road or Alley. Alley seams use alleyWidth (narrower, ~1-1.5m). Block positions computed from per-seam cumulative spacing.
  • Scanner impact: Alley voxels painted with MAT_ALLEY (133) — cobblestone material. Scanner picks them up as pathable nodes with higher tick cost (narrow, obstructed, slower).
  • Pathfinding: Alleys create secondary routes — flanking, escape, concealment. Higher tick cost = AI prefers roads unless tactical advantage or roadblock forces detour.
  • Tactical: Alleys are concealed from main street view. Crates/ash bins in alleys provide cover. Cars on roads provide cover.
  • Layout control: CityLayout gains per-seam type metadata. Generator can decide alley frequency (e.g., every 3rd seam is an alley, or random with seed).
