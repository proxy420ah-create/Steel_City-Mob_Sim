Reading the matrix

  • Cyan dials are pure inputs — most are static fields now: one value, every character, no drift.
  • Orange channels are broadcast-all / evaluate-individually. Nothing is scoped at emit time.
  • Purple blackboard is the per-fighter memory the engines argue over.
  • Dashed flavor nodes consume events but never feed back — impacts are audio/damage only by user rule.
  • Red-labeled edges are interrupts — they bypass normal ordering (flank reload-cancel, suppression gate).
