Firing Mechanics

Hitscan raycast — not projectile physics. Check collision world for wall hits, then check target in firing arc. Accuracy modified by distance, cover quality, movement.

Rendering: minor (tracer VFX)
🧠

Combat AI

State machine: IDLE → ALERT → MOVING_TO_COVER → IN_COVER → FLINCH/FALLING. Uses existing Pathfinder + WaypointGraph for navigation.

Rendering: none
💥

Hit / Death

Gameplay state flag + procedural animation. No ragdoll — voxel character rotates to "fallen" pose. Health tracks 0-1 per instance.

Rendering: shader animation only

🛡️ Cover System — Two Approaches

Cover is a gameplay query, not a rendering problem. Two approaches with different trade-offs.

✅ Approach A: Cover Points

Query existing collision world for cover positions

  • Scan VoxelCollisionWorld for wall-adjacent empty voxels
  • Cache cover points at load time (invariant computation!)
  • Zero rendering impact — buildings stay Tier 1 baked
  • Hoods pathfind to nearest cover point
  • Cover quality: full wall (1.0), corner (0.8), vehicle (0.6), half wall (0.5)
  • Fast to implement — uses existing systems
RECOMMENDED — Phase 2

🔲 Approach B: Dynamic Cover Props

Physical cover objects — cars, barrels, crates

  • New Tier 2 instanced objects (position + health in buffer)
  • Destructible — promote to Tier 3 on destruction
  • Requires new voxel asset pipeline (cover prop models)
  • More visual richness, more tactical depth
  • Debris on destruction = short-lived particle effect
  • More complex than Approach A
PHASE 3+ — after A is working
💡 Invariant Computation Note

Cover points are derived from building geometry that doesn't change during gameplay. This is a "do once" computation — cache cover points at load time. See INVARIANT_COMPUTATION_PRINCIPLE.md.

🚶 NPC Animation Without Skeletons

Voxel characters are raymarched volumes — no skeletal rigs. Four techniques, from simplest to most expressive.

🟢 Technique 1: Procedural Shader

Math-driven offsets applied to the entire body in the shader. No pre-authored poses, no limb separation. Sin waves, rotation, exp decay. Like RimWorld — the whole figure moves as one block.

Idle Breathing
Firing Recoil
Hit Flinch
Falling (rotation)
✅ Zero memory cost   •   Fast to implement   •   ❌ No limb articulation — whole body only   •   ❌ RimWorld-like feel

🔵 Technique 2: Voxel Swap (Stop-Motion)

Multiple pre-authored voxel poses stored in an atlas buffer. poseIndex selects which pose to render. Switching is instant — no interpolation. Stop-motion/claymation feel.

Walk (2-frame)
Fall (3 poses)
Crouch toggle
✅ Each pose can be completely different shape   •   ✅ Artist-directable   •   ❌ Choppy (no interpolation)   •   ❌ Memory = poses × voxel count

🟠 Technique 3: Voxel Groups (Articulated Limbs)

Voxels tagged with groupID (head, torso, arms, legs). Shader applies independent transforms per group. Limbs move separately — arms swing, legs stride, head turns. This is the articulated option.

Walk (legs + arms)
Aim (arms raise)
Head tracking
Crouch (legs + torso)
✅ Real limb articulation   •   ✅ Smooth, GPU-driven   •   ✅ Head tracking, arm aiming   •   ❌ Requires re-authoring models with group tags   •   ❌ Most shader complexity

🟣 Technique 4: Morph Targets (Pose Blending)

Author 2-4 extreme poses. Shader blends between them by weight parameter. Smooth interpolation — but all poses must have identical voxel topology (same count, same ordering).

Crouch blend
Lean blend
Stumble recover
✅ Smoothest transitions   •   ✅ Can blend multiple poses   •   ❌ Topology must match   •   ❌ Memory = poses × voxel count   •   ❌ Still whole-body (no per-limb)

🎯 If You Want Articulated Characters (Not RimWorld-Style)

Technique 3 (Voxel Groups) is the clear winner for articulated movement — arms raise to aim, legs stride independently, head tracks targets. It's more work (re-author models with group tags + shader complexity) but gives the limb-level articulation you want.

Recommended hybrid approach: Use Technique 1 (Procedural) for cheap background NPCs (walking bob, breathing — RimWorld-style is fine for ambient crowds) and Technique 3 (Voxel Groups) for combat participants (hoods in combat, police, anyone aiming/falling/taking cover). This way only the ~4-20 characters in combat need the expensive articulated path, while 50+ ambient NPCs use the cheap procedural path.

Technique 2 (Voxel Swap) can supplement both — use it for death poses (2-3 discrete poses, stop-motion is fine for falling). Technique 4 (Morph Targets) is optional — nice for smooth crouch blends but not essential if Voxel Groups already handles crouching.

💡 Instance Buffer Evolution

Current: Vector4(x, y, z, yaw) = 16 bytes → Phase 1: +animState, animTime = 24 bytes → Phase 2: +faction, health = 32 bytes → Phase 3 (groups): +float4 groupTransforms[4] = 96 bytes (only for grouped models). All backward-compatible — unused fields zeroed.

🚗 Vehicle Physics — Three Tiers

Match physics complexity to gameplay role. Not all vehicles need physics.

TIER A
Rolling Sphere

Single Rigidbody sphere + car mesh parented. Physics handles rolling. Steering rotates mesh.

✓ Trivial to implement
✓ Near-zero tuning
✗ No suspension
✗ No flipping
Use for: civilian traffic, fleeing cars
✅ RECOMMENDED — civilians
TIER B
Raycast Suspension

4 downward raycasts → spring-damper forces. Steering = torque. Lateral friction cancels drift.

✓ Full control over feel
✓ Can flip!
✓ No WheelCollider bugs
✗ Requires tuning
Use for: combat vehicles, police cruisers
✅ RECOMMENDED — combat
TIER C
WheelCollider

Unity PhysX WheelColliders. Automatic suspension, friction, slip curves.

✓ Built-in
✗ Notoriously finicky
✗ Unstable at high speed
✗ Highest perf cost
Use for: nothing in our game
❌ SKIP — overkill for mob sim

💡 Key Physics Techniques

Velocity-Time Curve — Designer draws acceleration profile as AnimationCurve. No physics PhD needed.
Anti-Roll Bar — Stabilizing force when tilted. Prevents accidental flips, allows extreme-maneuver flips.
Lateral Friction — Configurable "stickiness" (1.0 = grip, 0.7 = drift, 0.0 = ice). Lower = more dramatic chases.
Downforce — Downward force proportional to speed. High speed = more grip, harder to flip. Low speed = easier to flip from collision.

Firing From Vehicles

Hoods are still Tier 2 instanced. "Popping out of window" = position offset + animation state, not geometry change. Firing arc limited by window opening.

Rendering: minor (instance offset)
🔄

Vehicle Damage States

Intact → light damage (smoke) → heavy damage (fire) → disabled (not moving) → wrecked (burned out shell). Each state changes visual + physics behavior.

Rendering: Tier 2→3→1 promotion
🤸

Flipping

Raycast suspension + center of mass + anti-roll bar. High-speed collision applies enough torque to flip. Once flipped = disabled, hoods bail out on foot.

Rendering: full rotation in buffer
💥

Vehicle → Pedestrian

Car hits hood on foot → gameplay state change (injured/dead) + brief procedural fall animation. No physics ragdoll needed.

Rendering: shader animation
💡 New Tier Transition Pattern: Tier 2 → Tier 3 → Tier 1

Vehicles need a pattern not in the current DYNAMIC_OBJECT_RENDERING_TIERS.md: instanced (cruising) → individual (physics active, unique damage) → baked as static debris (wrecked). This should be documented when implementation begins.

🐝 Traffic & Swarm Behavior

Civilian traffic reacts to combat — emergent chaos from simple rules.

📏

Bumper System

Forward raycast "bumper" on each vehicle. Too close → decelerate. Very close → stop. Creates natural accordion traffic jams without pathfinding recalculation.

Rendering: none
🏃

Flee Vector

When combat noise reaches civilian vehicle: switch from waypoints to flee mode. Direction = away from noise source. Simple obstacle avoidance via left/right raycast. Creates emergent scattering.

Rendering: none
🎯

Formation Following

Chase car pathfinds to target's predicted future position (current + velocity × lookahead), not current position. Creates realistic interception, not train-following.

Rendering: none
🚫

Stuck Detection

If vehicle hasn't moved X meters in Y seconds: attempt reverse + go around. If still stuck → abandon vehicle, hoods exit on foot. Vehicle becomes Tier 1 bake candidate.

Rendering: none

💡 Rendering Impact: None (Beyond Entity Count)

Police are just another Tier 2 instanced character. Police cruisers are just another Tier 2 vehicle. The renderer doesn't care about factions — it just draws instances. Peak combat: ~45 Tier 2 instances + 2-3 Tier 3 vehicles. Well within budget.

⚠️ Roadblocks = Collision World Mutation

Roadblocks are the first time we'd modify the collision world after load. Needs: dirty sector flag → sector rebake → cover point cache invalidation for affected sectors.

💡 Impact on GPU-Driven Rendering Plan

Phase 1 (TRS Cache): ✅ No impact — buildings still don't move
Phase 2 (Buffer Pooling): ⚠️ More important — vehicle tier promotions = frequent buffer updates. 50+ entities in combat = frequent instance buffer rebuilds. Zero-GC becomes critical.
Phase 3-5: ✅ Still valid for buildings. Vehicles may stay on DrawMeshInstanced.
Phase 6 (Scale Test): ⚠️ Needs revision — vehicle physics adds CPU cost not in original plan.

Phase 1: Animation Foundation

Expand instance buffer (animState + animTime). Walking bob, idle breathing in shader. Test with existing NPC population. No gameplay change.

Phase 2: Street Combat

Cover point scanner, combat AI state machine, firing mechanics (hitscan + tracer), recoil/flinch/fall animation, faction system. Deliverable: two hoods fight, one goes down.

Phase 3: Vehicle Physics

Sphere physics for civilians, raycast suspension for combat vehicles. Velocity-Time curves, anti-roll, lateral friction, downforce. Tier 2→3 promotion system. Deliverable: cars drive, crash, flip.

Phase 4: Vehicle Combat

Vehicle AI (chase, engage, flee), formation following, firing from windows, disable → hoods exit, debris + fire particles. Deliverable: car chase with gunfire, crash, bail out.

Phase 5: Traffic Swarm

Bumper system, flee vectors, stuck detection, vehicle → pedestrian impact. Deliverable: gunfire causes civilian cars to scatter, traffic jams, abandoned cars.

Phase 6: Police Escalation

Noise/threat event system, police AI states, dispatch logic, roadblocks (collision world mutation). Deliverable: gunfight triggers police, cops engage, roadblocks cause crashes.

Phase 7: Polish

Voxel group transforms for limb animation, cover props (Approach B), vehicle fire glow, head tracking. Deliverable: hoods aim arms, crouch behind props, burning vehicles glow.
