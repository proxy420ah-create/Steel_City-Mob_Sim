2. Body Region Map

The naked base template is divided into named 3D regions. Each region can receive a different material ID for clothing.

Region Definitions (16×32×10 grid)

HAT
Y 28-31, X 0-15, Z 0-9 — optional, can be empty
HEAD
Y 23-27, X 4-11, Z 2-7 — skin material, accessories overlay
TORSO
Y 13-22, X 1-15, Z 1-8 — suit jacket, shirt, tie, coat
ARMS
Y 13-22, X 0-1 & 14-15, Z 2-8 — sleeves match torso
HANDS
Y 13-14, X 0-1 & 14-15, Z 3-7 — skin, gloves override
LEGS
Y 2-12, X 3-5 & 10-12, Z 2-7 — pants, overcoat skirt
FEET
Y 0-1, X 3-5 & 10-12, Z 2-7 — shoes, boots
Clothing = material override per region. Naked base uses skin (103/122) for all regions. Applying an outfit just changes material IDs for torso, legs, arms, feet — no geometry change needed.

Stencil mechanism: Each garment is a small array of [x, y, z, matId] offsets. To apply, add anchor position to each offset and set voxels. To remove, delete those voxel keys. This is essentially your current preset system but decomposed into individual reusable pieces.

5. Voxel Layer Stack

How clothing data layers onto the naked base. Each layer is applied in order — later layers can override earlier ones.

Layer 0: Naked Base
Skin voxels (mat 103/122) in all body regions. No clothing.
Layer 1: Region Materials
Override material IDs per region: torso→suit, legs→pants, feet→shoes, arms→sleeves
Layer 2: Garment Stencils
Stamp accessory voxels: hat, tie, badge, glasses, cigar. Adds new voxels at anchor positions.
Layer 3: Color Variation
Seeded RNG picks from role palette: suit color, hat color, tie color. Same role, different look.
Layer 4: Final Character
Baked voxel grid with material IDs. Ready for .stasset export or runtime material swap.

6. Unity Runtime — Outfit Swapping

At runtime, swapping outfits is just changing material IDs on existing voxels. No geometry rebuild, no re-baking. The ComputeBuffer updates with new material IDs per region.

State A: Hoodlum (suit)
voxelMap: [0,13,1] → 126 (suit blue) [0,13,2] → 126 (suit blue) [3,2,2] → 126 (pants blue) [0,28,0] → 126 (fedora blue) [7,15,1] → 120 (red tie) [4,26,2] → 109 (sunglasses)
↔
Swap material IDs per region only. Same voxel positions, different colors.
↔
State B: Hoodlum (overcoat)
voxelMap: [0,13,1] → 108 (overcoat) [0,13,2] → 108 (overcoat) [3,2,2] → 126 (pants, same) [0,28,0] → 126 (fedora, same) [7,15,1] → 120 (red tie, same) [4,26,2] → 109 (sunglasses, same)
Performance: Material ID swap = single ComputeBuffer.SetData call. No mesh rebuild, no re-baking, no GPU pose recompute. Could swap 100 characters' outfits in a single frame.

7. Role-Based Color Palettes

Each role has a palette of acceptable materials per region. Seeded RNG picks from the palette to create visual variety within a role.
