    - You spawn ONE background subagent (run_subagent, is_background=true)

    - The relay runs ONE watch then reports. It must NEVER re-arm itself,
      spawn a second ear, run other commands, or edit files. Re-arm
      authority stays with YOU after you read its report.

  THE RELAY TASK, VERBATIM (spawn exactly this):
    "Run ONE `python -X utf8 commission_pulse.py CHAIR --since <n>` in
     the docs directory — where <n> is the carried watermark you read

     commands, no file edits — one watch then report."

  WAKE DISCIPLINE (arm-before-act, the law):
    - On every doorbell: spawn the next relay as your FIRST tool call —
      BEFORE reading the batch, BEFORE composing any reply. An act-then-
      arm host leaves a dead-ear window equal to its whole compose time;

      re-arm until the flag clears.
